# Wireless-Message-transfer-4-bit-Parallel-
This project aims to create a wireless data transfer system between two laptops using  infrared (IR) light instead of Bluetooth or RF. 
<br>
Unlike Bluetooth, which sends one bit at a time (serial), our system sends multiple bits 
in parallel using: 
• 32 IR LEDs (transmitter) 
• 4 Photodiodes (receiver)
The LEDs are divided into 4 zones, each zone containing 8 LEDs. 
Each zone is detected by one photodiode. 
This allows us to transmit 4 bits at the same time, giving a very high data rate.
