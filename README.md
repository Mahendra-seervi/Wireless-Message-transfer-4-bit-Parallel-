# Wireless-Message-transfer-4-bit-Parallel-
This project aims to create a wireless data transfer system between two laptops using  infrared (IR) light instead of Bluetooth or RF. 
<br>
Unlike Bluetooth, which sends one bit at a time (serial),<B> our system sends multiple bits</B> <br>
in parallel using: <br>
• 32 IR LEDs (transmitter) <br>
• 4 Photodiodes (receiver) <br>
The LEDs are divided into 4 zones, each zone containing 8 LEDs.  <br>
Each zone is detected by one photodiode. <br>
This allows us to transmit 4 bits at the same time, giving a very high data rate. <br>
